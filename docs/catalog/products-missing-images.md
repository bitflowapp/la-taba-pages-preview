# Productos sin imágenes

Todavía no se recibió un catálogo real aprobado. No hay productos comerciales
para descargar ni imágenes que puedan asociarse con seguridad.

Al recibir el CSV, ejecutar el validador y agregar aquí cada SKU sin fuente
autorizada. Mantenerlo `available=false` hasta que la auditoría indique
`APROBADA`; usar `REVISAR` ante cualquier duda de variante, capacidad, envase o
cantidad del pack.
