## Catálogo comercial con imágenes aprobadas

No hay fuentes comerciales aprobadas en este manifiesto. El pipeline comercial permanece
fail-closed y exige auditoría de fuente y derechos antes de publicar imágenes nuevas.

El catálogo de 22 bebidas disponible mediante `?demo=1` se valida por separado con
`npm run catalog:images:verify`; no habilita esas imágenes para uso productivo.
