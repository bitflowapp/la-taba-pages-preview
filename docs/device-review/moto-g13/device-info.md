# Dispositivo físico utilizado

La misión solicitaba un Moto G13. El equipo conectado y autorizado por ADB fue un **motorola moto g15 (lamu)**; por eso esta evidencia no atribuye la prueba a un G13.

| Dato | Resultado observado |
| --- | --- |
| Sistema | Android 15 (API 35) |
| Navegador | Chrome 150.0.7871.186 |
| Pantalla física | 1080 × 2400 px, 400 dpi, 60 Hz |
| Área CSS visible en Chrome | 432 × 815 px en vertical |
| Navegación | Botones de Android, orientación vertical |
| Método | Toques y permisos reales en Chrome normal; ADB sólo para observación y capturas |

La revisión no limpió aplicaciones, fotos ni datos generales de Chrome. Los escenarios utilizaron pedidos, direcciones y contactos sintéticos. Las coordenadas del equipo no se registran en esta documentación ni en las capturas versionadas.

## Alcance de dispositivo

- Se comprobaron áreas táctiles, barra de Chrome, barra de navegación Android, teclado, recarga, volver atrás, cambio entre pestañas, bloqueo/desbloqueo y permisos de ubicación.
- La sesión publicada se abrió en Chrome normal, no incógnito.
- La cobertura es representativa del dispositivo probado, pero no sustituye una validación literal en Moto G13.
