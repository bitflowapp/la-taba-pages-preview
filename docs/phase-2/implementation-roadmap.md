# Implementation roadmap

## Fase 1

Demo estatica actual.

- Catalogo.
- Carrito.
- Checkout por WhatsApp.
- Modo negocio demo.
- Vista de repartidor demo.

## Fase 2

Cargar productos reales, fotos y WhatsApp de La Taba.

- Catalogo real.
- Fotos reales.
- Precios y combos reales.
- Zonas de entrega reales.
- WhatsApp final del negocio.

## Fase 3

Base de datos + pedidos reales.

- Guardar pedidos en una base de datos.
- Guardar clientes frecuentes.
- Guardar stock real.
- Guardar historial de estados.
- Realtime basico para ver nuevos pedidos.

## Fase 4

Panel negocio real y stock persistente.

- Login real.
- Panel de pedidos.
- Control de stock persistente.
- Edicion real de productos.
- Reportes simples.

## Fase 5

Rider real, estados en tiempo real y notificaciones.

- Asignacion de pedidos a repartidor.
- Cambios de estado en tiempo real.
- Salida del local.
- Entrega confirmada.
- Notificaciones internas.

## Fase 6

Pagos, clientes frecuentes y app instalable o nativa si conviene.

- Pagos online.
- Clientes frecuentes.
- Beneficios o promos recurrentes.
- Mejor instalacion como PWA.
- App nativa solo si el uso lo justifica.
