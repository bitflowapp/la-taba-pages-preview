# Proximas fases

## Fase 1: Demo web/PWA

Base actual para presentar y validar con La Taba.

- Catalogo de productos.
- Carrito.
- Envio a domicilio y retiro en local.
- Pedido armado por WhatsApp.
- Administracion demo con PIN.
- Vista demo para repartidor.
- Publicacion en GitHub Pages.

## Fase 2: Pedidos reales con base de datos

Objetivo: que los pedidos queden guardados y puedan consultarse desde distintos dispositivos.

- Base de datos para pedidos.
- Historial de pedidos.
- Estados persistentes.
- Respaldo de datos.
- Mejor control de errores.

## Fase 3: Panel negocio real, clientes y stock persistente

Objetivo: convertir la administracion demo en una herramienta diaria para el comercio.

- Login real para el negocio.
- Panel real de pedidos.
- Clientes frecuentes.
- Stock persistente.
- Edicion de productos desde panel.
- Reportes simples de ventas.

## Fase 4: Pagos, repartidor y notificaciones

Objetivo: profesionalizar la operacion si el volumen lo justifica.

- Pagos online.
- Notificaciones de nuevos pedidos.
- Vista de repartidor con datos reales.
- Confirmaciones de entrega.
- Mapa o GPS si aporta valor operativo.

## Fase 5: App instalable o nativa

Objetivo: decidir si conviene invertir en una app mas fuerte.

- PWA mejorada con instalacion guiada.
- App nativa solo si hay uso frecuente suficiente.
- Mejor experiencia para clientes recurrentes.
- Integracion con promociones, cupones o fidelizacion.
